# Grainfall

브라우저에서 돌아가는 픽셀 물리 샌드박스입니다. 마우스로 모래, 물, 용암, 불, 식물을 그리면 서로 반응합니다.

**▶ 데모: https://rhd8rhd724.github.io/grainfall/**

라이브러리나 빌드 도구 없이 순수 JavaScript(ES 모듈)와 Canvas만 씁니다.

## 이런 게 일어나요

- 모래는 쌓이고, 물속으로 가라앉습니다.
- 물은 옆으로 퍼지며 평평해집니다.
- 용암이 물에 닿으면 **돌**이 되고 **수증기**가 피어오릅니다.
- 수증기는 위로 올라가다가 가끔 다시 **물방울**로 떨어집니다.
- 불은 나무와 식물로 번지고, 연기를 남깁니다. 물이 닿으면 꺼집니다.
- 식물은 닿아 있는 물을 먹으며 자랍니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 왼쪽 드래그 | 선택한 재료 그리기 |
| 오른쪽 드래그 | 지우기 |
| `1`–`9`, `0` | 재료 선택 (`0` = 지우개) |
| `Space` | 일시정지 / 재생 |
| `C` | 전체 지우기 |

## 어떻게 동작하나

- 화면은 240×160 칸의 격자이고, 칸마다 종류·수명·색 변화 값을 `Uint8Array`에 저장합니다.
- 매 틱마다 아래 줄부터 위로 훑으며 각 칸의 규칙을 적용합니다. 좌우 방향은 틱마다 번갈아 바꿔서 한쪽으로 쏠리지 않게 합니다.
- 무게(밀도)가 큰 재료는 가벼운 재료와 자리를 바꾸며 가라앉습니다. 그래서 규칙 하나로 "모래가 물에 가라앉기", "수증기가 물속에서 떠오르기"가 같이 해결됩니다.
- 같은 틱에 두 번 움직이지 않도록 칸마다 마지막으로 움직인 틱 번호를 기록합니다.
- 화면 주사율과 상관없이 초당 60틱으로 고정해서 시뮬레이션합니다.
- 그리기는 미리 계산한 색상표로 `ImageData`의 픽셀을 한 번에 채운 뒤 `putImageData`로 올립니다.

## 구조

```
index.html
style.css
src/
├── main.js       # UI, 입력, 메인 루프
├── world.js      # 격자, 떨어지기·흐르기 같은 이동
├── rules.js      # 용암, 불, 식물, 기체 반응 규칙
├── elements.js   # 재료 정의 (밀도, 가연성, 색)
├── render.js     # 캔버스 렌더링
└── scene.js      # 시작 화면 데모 장면
test/
└── world.test.mjs  # 규칙 테스트 (헤드리스)
```

## 로컬에서 실행

ES 모듈을 쓰기 때문에 파일을 더블클릭하지 말고 로컬 서버로 여세요.

```bash
python3 -m http.server 8000
```

그다음 http://localhost:8000 을 엽니다.

테스트는 Node로 돌립니다.

```bash
npm test
```
