# grainfall

브라우저에서 돌아가는 픽셀 모래 시뮬레이션

데모: https://rhd8rhd724.github.io/grainfall/

라이브러리 없이 js + canvas로 만듦

## 되는거

모래, 물, 돌, 나무, 식물, 불, 용암, 수증기, 연기

용암이 물에 닿으면 돌이랑 수증기 됨. 불은 나무랑 식물로 번지고 물 닿으면 꺼짐. 수증기는 올라가다가 가끔 다시 물로 떨어짐. 식물은 옆에 물 있으면 자람

## 조작

마우스 왼쪽 그리기, 오른쪽 지우기 / 1~9, 0으로 재료 선택 / space 일시정지 / c 전체 지우기

## 실행

ES module이라 파일 그냥 열면 안되고 로컬 서버로 열어야함

```
python3 -m http.server 8000
```

테스트는 npm test

## 메모

240x160 격자를 Uint8Array로 들고있음. 아래 줄부터 업데이트하고 좌우 방향은 매 틱마다 번갈아가면서 돌림 (안그러면 한쪽으로 쏠림). 밀도 높은게 낮은거랑 자리 바꾸는 방식이라 모래가 물에 가라앉는것도 따로 안짜도 됨
